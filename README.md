# «Дверь» — кинематографичная катсцена для Minecraft

Датапак с короткометражкой на ~1 мин 50 с: житель и зомби разговаривают на острове,
который собирается из блоков над облаками на закате.

```
/function cutscene:start   — запустить (от имени игрока)
/function cutscene:stop    — прервать в любой момент и вернуть всё как было
```

## Что внутри

- **Камера как в кино.** Игрок переводится в режим наблюдателя и смотрит глазами невидимой
  камеры: пролёт сквозь облака, крупные планы, съёмка через плечо, финальный отъезд краном.
  Движение считается каждый тик со сглаживанием (smoothstep) и дополнительно интерполируется клиентом.
- **Диалог.** Субтитры печатаются по буквам с именем говорящего, у каждого персонажа свой
  «голос», говорящий кивает в такт.
- **Постройки появляются плавно.** Когда герои вспоминают дверь, дом, колокольню и строят лестницу
  к луне, блоки вылетают по одному, вращаясь и вырастая из точки. В финале всё так же растворяется.
- **Мир не трогается.** Сцена целиком собрана из `block_display` на высоте Y=230 прямо над игроком.
  В мир ставятся только невидимые блоки света, и они убираются в конце. После катсцены игрок
  возвращается на прежнее место, с прежним взглядом и режимом игры.

## Установка

1. Положи папку (или zip) с `pack.mcmeta` в `saves/<мир>/datapacks/`.
2. В игре: `/reload`, затем `/function cutscene:start`.

Версии: Java Edition 1.21 – 26.3 (проверено на 1.21.1, 1.21.11, 26.1 и 26.3).

## Важно знать

- Время суток перематывается **вперёд** до заката — так задуман свет в сцене.
- На мирной сложности зомби исчезает, поэтому катсцена попросит включить `/difficulty easy`.
- Смотреть может один игрок за раз. Лучше всего выглядит в обычном мире (облака, закат, луна).
- Нажать F1 перед запуском — и интерфейс не будет мешать.

## Как менять

Все функции в `data/cutscene/function` сгенерированы скриптом `tools/build.py` — там лежат
реплики, ракурсы камеры и постройки. После правок: `python3 tools/build.py`.
